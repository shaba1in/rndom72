# Сайт КП «РН-ДОМ»

Одностраничный сайт новых готовых домов в Тюмени (м-н Казарово). Чистый HTML, CSS и JavaScript, без сборки и фреймворков.

## Структура проекта
```
rn-dom-site/
├── index.html          # вся разметка страницы (все разделы сайта)
├── otzyvy.html         # страница «Все отзывы» (видеоотзывы, список пополняется)
├── css/style.css       # стили и цвета бренда (переменные в :root)
├── js/main.js          # анимации, форма звонка, окно «Политика конфиденциальности»
├── images/
│   ├── logo.png, favicon.png       # логотип и иконка вкладки
│   ├── about-cover.jpg             # обложка видео на главном экране
│   ├── review-<имя>.jpg            # обложки видеоотзывов
│   ├── house-<тип>-1..3.jpg        # фото домов (3 на каждый вариант)
│   └── plan-<тип>.png              # планировки домов
├── videos/             # сюда класть видео (о посёлке, отзывы)
├── package.json        # запуск локального сервера (npm run dev)
├── vercel.json         # настройки публикации на Vercel
├── robots.txt, .gitignore, DEPENDENCIES.md
└── README.md
```

## Запуск на компьютере
**Самый простой способ:** дважды кликните по `index.html`, сайт откроется в браузере. Шрифт Montserrat подгружается из интернета.

**Через локальный сервер** (ближе к реальной работе сайта):
- С Node.js 18+: `npm install`, затем `npm run dev`, открыть http://localhost:3000
- С Python 3: `python3 -m http.server 3000` (Windows: `python -m http.server 3000`), открыть http://localhost:3000

Подробнее о зависимостях: `DEPENDENCIES.md`.

## Как редактировать
| Что изменить | Где |
|---|---|
| Тексты, телефоны, адрес, почта | `index.html` (ищите по тексту, например `+7 904`) |
| Цвета бренда | `css/style.css`, блок `:root`: `--dark` (графит), `--coral` (красный) |
| Логотип | заменить файл `images/logo.png` (имя оставить) |
| Фото и планировки домов | файлы в `images/` (`house-1f-garage-1.jpg`, `plan-1f-garage.png` и т. д.). Чтобы заменить, положите новый файл с тем же именем. Чтобы добавить фото, вставьте ещё один `<img src="images/...">` внутрь блока `<div class="sl">` нужной карточки и поправьте счётчик `1 / 4` |
| Видео о посёлке (главный экран) | Уже подключено с Rutube. Чтобы заменить, в `index.html` у блока `<div class="vid cv" data-rutube="…">` поменяйте ID в `data-rutube` (часть ссылки после `/video/`) и файл обложки `images/about-cover.jpg` |
| Видеоотзывы | Страница `otzyvy.html` (все отзывы) и блок «Видеоотзывы» на главной. Чтобы добавить отзыв, скопируйте блок `<article class="rc rv">…</article>`, замените ID видео в `rutube.ru/play/embed/ID/` (ID берётся из ссылки на ролик после `/shorts/` или `/video/`), имя и тезисы. Новые отзывы добавляйте на `otzyvy.html`, а на главной оставляйте 3 самых свежих |
| Ссылка на Instagram | `index.html`, раздел «Контакты», комментарий `ВСТАВЬТЕ ссылку на Instagram` |
| Текст политики конфиденциальности | `index.html`, блок `<dialog id="pdlg">` |

Видеофайлы лучше сжимать (формат MP4, H.264, до 1080p) и держать каждый до 20–30 МБ. Для длинных видео удобнее загрузить их на видеохостинг и вставить через `<iframe>`.

## Публикация: GitHub + Vercel
1. **GitHub.** Создайте новый репозиторий на https://github.com/new (например, `rn-dom-site`). В папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Первая версия сайта РН-ДОМ"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/rn-dom-site.git
   git push -u origin main
   ```
2. **Vercel.** Зайдите на https://vercel.com, войдите через GitHub, нажмите **Add New → Project**, выберите репозиторий и нажмите **Deploy**. Настройки менять не нужно: Framework Preset — `Other`, Build Command и Output Directory — пустые. Каждый следующий `git push` будет автоматически обновлять сайт.
3. **Свой домен.** В проекте Vercel откройте **Settings → Domains**, добавьте домен и пропишите у регистратора DNS-записи, которые покажет Vercel. HTTPS-сертификат выдаётся автоматически.

## Чек-лист перед запуском
1. **Заявки из формы.** Форма «Обратный звонок» сейчас только показывает «Спасибо» и никуда не отправляет данные. Подключите приём заявок на почту или в Telegram (например, сервис Formspree или серверная функция на Vercel). Форма: блок `<form id="f">` в `index.html`, обработчик в `js/main.js`.
2. **Instagram.** В разделе «Контакты» ссылка ведёт на главную Instagram. Вставьте ссылку на аккаунт компании (в коде есть комментарий `ВСТАВЬТЕ ссылку на Instagram`) или удалите иконку вместе с пометкой о Meta.
3. **Политика конфиденциальности** составлена по общему шаблону. Добавьте ИНН/ОГРНИП оператора и покажите текст юристу (блок `<dialog id="pdlg">` в `index.html`).
4. **Данные о домах.** В карточках стоит «Площадь и цена: по запросу». Когда будут данные, впишите их в карточки и в описания внутри окна «Узнать подробнее».
5. **Проверьте контакты и условия:** телефоны, адрес, почту, «ипотека от 6%», «гарантия 3 года», «15 минут от города».
6. **Видео Rutube** (главный экран и отзывы) проверьте на опубликованном сайте с телефона и компьютера. Если плеер не запускается, ссылка «Смотреть на Rutube» под каждым отзывом откроет ролик на самом Rutube.
7. **Домен.** После подключения домена добавьте в `<head>` обеих страниц `<link rel="canonical" href="https://ВАШ-ДОМЕН/">` (для `otzyvy.html` с `/otzyvy`).
8. **Тексты отзывов.** Проверьте написание имён и формулировки тезисов в блоках видеоотзывов.
