# Зависимости проекта

Сайт статический (HTML + CSS + JavaScript), **собирать его не нужно**, фреймворков и библиотек в нём нет.

## Для работы сайта (runtime)
| Что | Откуда | Зачем |
|---|---|---|
| Шрифт Montserrat | Google Fonts (подключён ссылкой в `index.html`) | Фирменный шрифт. Если интернета нет, браузер покажет системный шрифт, сайт продолжит работать. |

Больше ничего подключать не нужно: иконки встроены в `index.html` как SVG, скрипты написаны вручную без библиотек.

## Для разработки (необязательно)
Нужны только для удобного локального сервера. Сайт можно открыть и без них (см. README).

| Что | Версия | Установка |
|---|---|---|
| Node.js | 18 или новее | https://nodejs.org (кнопка LTS) |
| serve (локальный сервер) | ^14.2.4 | `npm install` в папке проекта |

### Установка и запуск
```bash
npm install     # установит serve (один раз)
npm run dev     # сайт откроется на http://localhost:3000
```

### Вариант без Node.js (нужен Python 3)
```bash
python3 -m http.server 3000     # macOS / Linux
python -m http.server 3000      # Windows
```
Затем откройте http://localhost:3000
